## 1. Page Purpose & Architectural Boundary

1. **Pure Presentation & Backend Delegation:**
   The Stress Lab provides interactive gross redemption stress testing and multi-scenario liquidity analysis. In accordance with architectural boundaries, the UI page performs **zero** business logic, ML inference, or mathematical transformations directly. It delegates entirely to pure, tested backend functions:
   * [`fundflow.stress.stress_outflow`](file:///Users/anny/Desktop/mutual-fund/src/fundflow/stress.py)
   * [`fundflow.stress.scenario_table`](file:///Users/anny/Desktop/mutual-fund/src/fundflow/stress.py)
   * [`fundflow.explain.generate_stress_narrative`](file:///Users/anny/Desktop/mutual-fund/src/fundflow/explain.py)
2. **Deterministic Data Flow:**
   Category reference AUM and baseline predictions are loaded via [`app/loaders.py:load_table`](file:///Users/anny/Desktop/mutual-fund/app/loaders.py) (`alerts` or `flows_category_month`). All displayed scenario values strictly match backend engine outputs.

## 2. Key Interface Sections & Display Rules

### 2.1 Critical Data Sufficiency Warning
A prominent warning banner is permanently displayed at the top of the interface:
> `⚠️ INSUFFICIENT_HISTORY: Historical flow history currently contains only 1 month (September 2024). Empirical residual uncertainty bands (P10/P90) and historical maximum rates are unavailable or descriptive-only. Statistical intervals require adequate multi-year history and are honestly withheld rather than fabricated.`

### 2.2 Category Selection & Reference Proxy Metrics
* **Category Selector:** Allows switching between monitored categories (`Large Cap`, `Mid Cap`, `Small Cap`, `Flexi Cap`, `Aggressive Hybrid`, `Corporate Bond`).
* **Metric Cards:**
  1. `OBSERVED · Reference AUM proxy`: Displayed in ₹ crore, tagged with the observation period (e.g. `2024-09`) and source.
  2. `FORECAST · Base forecast rate`: Point estimate redemption percentage produced by the walk-forward Ridge model.
  3. `SCENARIO · Base outflow proxy`: Projected gross redemption outflow (₹ crore) under central baseline assumptions.

### 2.3 Interactive Stress Scenario Input & Capping
* **Custom Rate Input:** Users can input hypothetical redemption rates ($0.0\%$ to $200.0\%$).
* **100% Capping Policy Notice:** If the custom rate exceeds $100.0\%$, the UI immediately renders an informative notice:
  > `ℹ️ Policy Notice: Input scenario rate exceeds 100.0%. Capped at 100.0% of reference AUM per FundFlow policy (gross redemptions cannot exceed available portfolio assets).`

### 2.4 Multi-Scenario Outflow Breakdown Table
Renders the complete table generated by `scenario_table()` with columns:
* `Scenario Name`: (Base Forecast, Empirical Lower P10, Empirical Upper P90, Moderate Stress 1.25x, Severe Stress 1.50x, Historical Max, Custom Scenario)
* `Scenario Type`: (`baseline`, `empirical_bound`, `multiplier_stress`, `historical_worst`, `custom`)
* `Rate (%)`: Raw scenario percentage
* `Effective Rate (%)`: Capped effective rate applied to assets
* `Estimated Outflow (₹ Cr)`: Computed gross redemption volume
* `Incremental Outflow (₹ Cr)`: Volume in excess of baseline
* `Status`: (`valid`, `capped_at_100`, `insufficient_history`, `unavailable`)
* `Assumption`: Plain-language premise governing the scenario

### 2.5 Finance-Safe Scenario Narrative & Disclaimers
* Displays rule-based narrative explanations generated by `generate_stress_narrative()`.
* Adheres strictly to finance-safe terminology: rejects causal claims, "liquidity crisis", "run", or panic statements.
* Discloses that reference AUM is a historical category proxy, not intraday liquid cash, and does not model secondary market depth or price impact.

## 3. Offline & Empty States

* **Missing Files:** If alerts or flow tables are absent or empty, the page renders an informative empty state banner without unhandled exceptions.
* **Offline Smoke Test:** Verified with network sockets blocked (`tests/test_ui_pages.py`).
